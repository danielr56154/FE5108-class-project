# FE5108 class project

Parts 1–5 of the Fall 2026 portfolio project. The write-up is separate. This repo is the code, the data, and the exhibits.

Uses pandas, numpy, matplotlib, scipy, and openpyxl.

```bash
python part1.py
python part2.py
python part3.py
python part4.py
python part5.py
```

Each script reads `data/` and writes only its own files in `exhibits/part1` through `exhibits/part5`. Sample windows and formulas are in `documentation/`.

The assignment is `class_project_handout.pdf`.
