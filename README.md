# FE5108 class project

Parts 1–3 of the Fall 2026 portfolio project. The write-up is separate. This repo is the code, the data, and the exhibits.

Uses pandas, numpy, matplotlib, scipy, and openpyxl.

```bash
python part1.py
python part2.py
python part3.py
```

Each script reads `data/` and writes only its own files in `exhibits/`. Sample windows, formulas, and the MSCI Momentum notes are in `documentation/`.

The assignment is `class_project_handout.pdf`.
